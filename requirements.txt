# --- Recommended: neural surface normals -----------------------------------
# StableNormal predicts normals straight from RGB instead of differentiating
# depth. It is the single biggest quality win in the pipeline: object
# boundaries stay sharp, and thin structures (chair legs, cables, window
# bars) appear at all — a depth map cannot resolve them, so no depth-derived
# method can recover them.
#
# Measured on a 1504px interior against the tuned analytic estimator:
#   halo  0.600 -> 0.250  (-58%)
#   noise 0.00718 -> 0.00585  (-19%)
#   cost  0.9 s -> 3.6 s per import, ~4.8 GB peak VRAM
#
# LICENCE: Apache-2.0 on both code and weights — no restriction, unlike the
# depth and albedo backends. Enabled automatically when diffusers is present;
# disable with --no-neural-normals.
#
# Weights (~2 GB) download on first use into models/stablenormal/.
diffusers==0.39.0
